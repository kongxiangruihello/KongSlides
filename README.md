# KongSlides

KongSlides 0.2.19 是面向高校课堂的 macOS 课件编辑与放映原型。应用使用 SwiftUI 与 AppKit，文档和素材保存在本机。最低支持 macOS 15。

PPTX 表格保留行列比例、合并单元格、文字与直接设置的纯色填充。导入后，双击表格或从右侧面板编辑单元格。导出 PPTX 时表格保持可编辑，投影和 PDF 也包含表格。依赖 PowerPoint 主题的表格样式及特殊边框会简化，导入报告给出提示。

PPTX 中可转换的文字、图片、纯色矩形和表格保留最外层组合，可整体移动或双击子对象单独编辑。嵌套组合会归入最外层，整体旋转、翻转和无法解析的变换见导入报告。支持为直箭头绑定矩形端点，移动矩形时连接线随之更新。

编辑时可点击左侧整张缩略图或页名选择幻灯片。使用 ↑／↓ 或 Page Up／Page Down 翻页，左侧标题栏也有上一页和下一页按钮。搜索时在匹配页之间翻页。点击页数或按 ⌘J 可按课件页码直达，支持全角数字。Home／End 跳到首页或末页，搜索时跳到第一个或最后一个匹配页。

「形状」菜单可插入直线和箭头。PPTX 的直线与直箭头可编辑端点、线宽、颜色和常见线型，并作为连接线导出。与其他形状的自动绑定会转为自由端点，弯折和曲线连接线会在导入报告中提示。

PPTX 导入会把母版和版式中的独立图片、文字、纯色矩形及直线放在正文后方，并标注来源。显式启用且有内容的静态页脚可随页导入。动态日期和自动页码暂不从母版生成，复杂对象的限制见导入报告。

PPTX 导入优先使用一次索引的 ZIP 读取器，减少长课件的子进程开销。导入报告可直接用对应 PDF 页修复并保留原诊断，支持导出清单和叠加对照。可调整左侧缩略图栏宽度，并导出整份课件的离线授课资料。编辑器加入网格总览、搜索命中、浏览历史、保存冲突提示、对象锁定和表格结构编辑。教师端提供课堂书签、讲解标记和史料出处，可按章节排练计时。编辑器支持命名快照、框选对象、对齐与等距分布。

长课件优先显示上次编辑页，可见缩略图按需绘制并缓存图片。「交换文件 → 查看打开耗时」显示读取、图片转换和首屏各阶段。导入报告汇总成功读取、已修复和待修复页，可打开下一个待修复页的 PDF 对照。

正常启动先显示 KongOffice 标识，再进入首页。首页可打开收藏或最近使用的课件，也可新建课件。编辑时点左上角房子回到首页，可使用「继续编辑」返回原课件。通过 Finder 打开时直接进入课件窗口。

首页支持「接着备课」、课程收藏分组、拖动排序、定位移走的文件，以及打开前预览、模板新建和课前准备。首页 JSON 备份保存收藏、最近记录与课件路径，导入会与本机记录合并。启动时若正在读取课件会显示真实进度。

## 运行

在 Mac 上安装 Xcode 16 或更新版本。下载并解压项目后，在项目根目录运行：

```sh
./Scripts/build-app.sh
open dist/KongSlides.app
```

构建脚本会生成适用于当前 Mac 架构的本地测试应用。日常编辑请通过生成的应用启动，应用包提供 Finder 文件关联。

## 首版操作

- 从“新建页”插入空白、标题或原文解读页。在左侧拖动缩略图，或使用右键菜单复制、上移、下移和删除页面。
- 双击文本框开始编辑。可插入图片和矩形，拖动调整位置，并在右侧设置尺寸、字号、颜色和前后层次。
- 按页编写讲稿，在左侧搜索正文、章节和讲稿。右侧的“章节名称”会显示在章节起始页的缩略图上，同名连续页面可用右键菜单整章上移或下移。
- 使用 ⌘S 保存 `.kongslides` 文件。应用本身管理可编辑对象与素材。
- 点击“放映”从当前页开始。连接扩展显示器时，投影显示幻灯片，主屏显示讲稿、当前页、下一页、计时和跳页控件。播放支持方向键、空格与 Esc。
- 导出投影 PDF 或基础的可编辑 PPTX。PPTX 保留文本、矩形、图片和讲稿。跨系统打开时可能因字体替换产生断行差异。

通过“交换文件”将已有 PPTX 的基础文本、图片、纯色形状和备注追加到当前课件。导入时会读取常见标题和正文占位框的位置及默认格式，保留可识别的文字字号、字体、对齐、行距和项目符号。已有课件的复杂母版、动画和复杂图表可能近似转换或跳过。原型把导入图片最长边缩至 2048 像素，便于控制课堂课件的文件大小。

## 长课件编辑

重新打开已保存的 `.kongslides` 课件时，会回到本机上次编辑的那一页。页序变化时按页面标识恢复，被删除的页面会回退到首页。浏览位置不会写入课件文件。

- 单击画布对象可拖动四角调整尺寸，图片默认等比缩放。选中图片后可等比适应、填充，或按百分比调整四边裁剪。基础图片裁剪可随 PPTX 导入和导出。
- 在缩略图栏用 Shift 或 ⌘ 选择多页，右键可复制、移位和删除。点击章节标题可折叠或展开，右键可重命名整章。
- 缩略图、画布对象和文字编辑各自处理复制粘贴，文稿支持 ⌘Z 和 ⇧⌘Z。
- 拖动讲稿区顶部可拉高，使用字号控件调整阅读尺寸。在专注视图中可逐页修改或连续阅读。
- 双屏时教师端可交换屏幕。断开外接显示器后保留页码并显示单屏控制条，按 C 可隐藏或显示控制条。重新连接可恢复双屏。

## 中文字体与图片外观

「放映前检查」会标出本机缺少的字体、采用替代字形的中文字符，以及找不到可用字形的字符，可点击定位到原页。用「全文替换字体」批量换成本机已安装的字体，保留已有字号、颜色和上下标。

图片可在右侧调整旋转、水平或垂直翻转和不透明度。基础旋转、翻转、不透明度和裁剪设置可随 PPTX 导入导出。

## 页面比例、局部格式和课件恢复

导入 PPTX 后会保留页面尺寸。右侧「幻灯片尺寸」可预览 16∶9、4∶3 或自定义尺寸，应用时等比缩放并留边。PDF 与 PPTX 导出沿用课件尺寸。

PPTX 中同一文本框的局部字号、粗体、字体、颜色和上下标可随文稿保存。选中文本框后可在右侧「局部文字格式」逐段调整已有样式。

编辑停顿后会生成本机恢复副本，正常关闭文稿时清理。意外退出后可在「交换文件 → 课件恢复」预览并打开为新文稿；恢复副本须由用户确认后才会删除。

## 迁移旧课件与设置备用页

可直接用「文件 → 打开」、Finder 的「打开方式」，或将 PPTX 拖入 KongSlides 窗口。PPTX 和原生课件都在当前窗口打开。PPTX 打开后可编辑，保存时写入独立的 `.kongslides` 文件。切换课件前可保存当前修改。从「交换文件」导入时可查看页数进度并取消。若某些页面无法读取，课件会保留带源页码的占位备用页，详细原因见导入报告。

通过「交换文件 → 打开课件」可在当前窗口打开原生课件或 PPTX。导入报告会随新课件显示。如需将幻灯片加入现有课件，可使用「追加 PPTX 页面到当前课件」。

可右击缩略图将选中的单页或多页设为备用页，也可在右侧版面属性切换当前页。顺序放映会跳过备用页。按 B 可黑屏或恢复，按 P 可启用临时画笔。双屏时在教师预览上标画，笔迹同步投影，翻页后自动清除。“备用页”菜单可临时调出页面，按 R 或点击“返回正片”可回到调出前的位置。PowerPoint 隐藏页状态随 PPTX 导入和导出。

投影 PDF 和学生配布 PDF 默认排除备用页，保存窗口可选择包含。教师讲稿 PDF 会保留并标记备用页。学生配布 PDF 的页号沿用课件顺序，便于课堂对照。「交换文件 → 导出本章授课资料」可把当前章的投影、讲稿和学生配布 PDF 一次存到同名文件夹。

在「交换文件 → 对照原稿 PDF」或 PPTX 导入报告中可打开一份参考 PDF。按原 PPTX 的源页码配对，也可手动换参考页。在需要保持原稿视觉效果时，可将单页替换为参考页图片，原讲稿、章节与备用页设置随页保留。

## 从讲稿生成课件

在“新建页 → 从提纲生成课件”粘贴 Markdown 或逐字讲稿。一级标题是课程名，二级标题分章，三级标题开启新页。`---` 也可以分页。`【投影】` 和 `【讲稿】` 用来区分投影文字和教师备注；未标记段落的去向可以统一设置，也可以在预览中逐段调整。预览显示实际页数，可以逐张预览续页、合并相邻组或从某段主动分页。讲稿默认放在首页，也可以把段落分配给指定续页。

“保存当前页为版式”把对象、图片和样式记入本机的版式库。从“从教学版式新建”可预览、插入或删除自定义版式。含至少两个文本框的版式也可用于生成课件，标题和正文分别使用从上到下、从左到右排列的前两个文本框。

在“交换文件 → 导出讲稿与配布 PDF”中可选择 A4 教师讲稿版或学生配布版。教师版含幻灯片和完整讲稿，长讲稿自动续页。学生版每页排两张或三张幻灯片，右侧留笔记区。

## 核对课件

- 在“交换文件 → 查看 PPTX 导入报告”查看字体替换、图片裁剪近似及未转换对象。可按「页面未读出」「内容未转换」「样式或效果差异」筛选，严重问题优先显示。点击问题可定位页面和可编辑对象。报告随课件保存，保留源文件页码。
- 点击工具栏“放映前检查”，定位文本可能截断或对象超出画布的页面。修改后可点击“重新检查”。放映、检查和 PDF 导出共用文字排版。

## 软件更新

从 0.1.0 首次升级时，请从 [GitHub 发布页](https://github.com/kongxiangruihello/KongSlides/releases) 下载新版 ZIP。退出旧版后，将解压的 `KongSlides.app` 放到可写位置，替换旧应用。课件文件独立保存。

从 0.1.1 起，KongSlides 会在启动后自动检查更新，检查成功后间隔至少一天。应用菜单提供“检查更新…”和“自动检查更新”开关。找到新版时，可下载已校验的安装包，并选择“退出并安装”。应用会先走正常退出流程，再由更新程序替换应用并重新打开。若启动命令失败，更新程序会尝试恢复旧版。

从 0.2.2 起，应用内更新显示下载百分比，随后显示校验、替换应用和重新启动等阶段。下载安装阶段由运行中的旧版负责显示，旧版升级至本版后即可在今后的更新中使用。

自动安装目前对应 Apple 芯片测试包。若应用由 macOS 在只读位置运行，或当前文件夹不可写，从 0.1.3 起可在更新窗口选择可写的文件夹安装新版。已有其他文件、同版或更新版本的位置会受到保护。

## 验证

在 Mac 上运行 `swift test`。检查覆盖 100 页文档的保存重开与 PDF 导出，以及 PPTX 文本、图片、讲稿和结构的导出与回读。在实际课堂使用前，请使用扩展屏试放一遍，并用目标电脑上的 PowerPoint 核查导出的版式。
